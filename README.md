# AI-interview-Agent

This repository contains three related interview-preparation projects:

- `Coding_Round_Standalone/`: standalone coding assessment app.
- `Jobjugad Agent/`: JobJugaad application and its interview, dashboard, and performance tools.
- `phase 1.1/`: earlier interview-agent implementation.

Configure API credentials through environment variables or local `.env` files. Do not commit credentials, virtual environments, session data, or interview recordings.
